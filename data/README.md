# Local dataset

This public repository intentionally contains no research dataset.

Place an authorized labelled CSV at `data/roman_urdu_sentiment.csv` with the following schema:

```csv
text,label
"example Roman Urdu message",positive
```

Do not commit private tweets, personally identifiable information, restricted annotations, or any dataset that cannot legally and ethically be redistributed. The root `.gitignore` excludes all files in this directory except this documentation.
